# Mari & Graftan

Wedding website for marigraftan.com. Netlify publishes every push to `main`.

- `index.html` is the whole site (English and Georgian).
- `media/sameba.mp4` is the opening film (natural colour, exposure lowered).
- `media/sameba-bw.mp4` is the same film in warm black and white. To switch, point both `<source>` tags in `index.html` to it.
- RSVPs are collected by Netlify Forms (form name `rsvp`).
